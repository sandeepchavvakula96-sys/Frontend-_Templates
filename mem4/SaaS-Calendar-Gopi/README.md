# FlowCal — SaaS Calendar

**User:** Gopi  
**UI Topic:** SaaS Calendar  
**Technology:** HTML, CSS, JavaScript

## Overview
FlowCal is a modern SaaS scheduling workspace combining calendar management, smart scheduling, team availability, productivity analytics, focus sessions, notifications, and an AI-style calendar assistant.

## Research / UI Pattern
SaaS calendars are commonly used in productivity platforms, team collaboration products, project-management tools, and scheduling applications. Modern patterns emphasize fast event creation, multiple calendar views, responsive layouts, conflict awareness, time-zone support, collaboration, and automation.

## What this implementation adds
- Premium glassmorphism SaaS visual language
- Month calendar with generated event pills
- Month navigation
- Month / Week / Day / Agenda controls
- Create-event modal
- Click-to-create on calendar dates
- Smart scheduling recommendation
- AI calendar assistant
- Team availability
- World clock
- Productivity analytics
- Focus timer
- Notifications center
- Profile panel
- Settings panel
- Command palette with Ctrl/Cmd + K
- Dark/light theme
- Responsive mobile sidebar
- Toast feedback for actions

## Run
Open `index.html` in a modern browser. No build system is required.
