# Crop Monitoring — Gopi

Premium agricultural UI template collection with four different designs.

## Templates
1. Crop Aurora
2. Agri Glass
3. Organic Farm
4. Agri Neon

## Features
Crop health, field intelligence, satellite monitoring, soil moisture, irrigation, weather, pest alerts, yield prediction, equipment tracking, AI assistant, analytics, reports, responsive UI, working modals and buttons.

Open `index.html` or use VS Code Live Server.
