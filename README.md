## Central Main Page

- Project cards
- Project names
- Project descriptions
- Search functionality
- Filtering

## How to Run

### Method 1 – Browser

1. Extract the project ZIP file.
2. Open the extracted folder.
3. Locate the root **`index.html`**.
4. Double-click `index.html`.
5. The main project dashboard will open.
6. Select any project card.

---

### Method 2 – Visual Studio Code

1. Open **Visual Studio Code**.
2. Select **File → Open Folder**.
3. Select the extracted **Gopi's Team** folder.
4. Open the root `index.html`.
5. Install the **Live Server** extension if required.
6. Right-click `index.html`.
7. Select **Open with Live Server**.
8. The main project dashboard will open.

---

## Important Project Structure Rule

The root `index.html` is the **main launcher**.

It should display only the **16 main projects**.

Individual template pages should remain inside their respective project folders.

For example:

```text
Climate-Dashboard-Sohni/
│
├── index.html
├── css/
├── js/
├── assets/
│
├── template1/
│   └── index.html
│
├── template2/
│   └── index.html
│
└── template3/
    └── index.html
```

Only:

```text
Climate-Dashboard-Sohni/index.html
```

is treated as the main project page.

The template pages remain available inside the project but are not shown as separate projects on the central homepage.
