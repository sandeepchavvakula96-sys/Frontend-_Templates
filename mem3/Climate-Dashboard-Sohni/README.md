# ClimateFlow - Sohni
Beautiful fictional climate dashboard for an educational UI project.

Modules: Overview, Weather, Air Quality, Climate, Carbon, Energy, Water, Alerts, Analytics and Profile.

Features: animated Earth-themed background, environmental metrics, charts, air-quality score, climate alerts, CSV export, location demo, climate challenge, responsive navigation and theme control.

Run by opening index.html.

All displayed environmental data is demo data and is not a live monitoring service.
