# MediNova — Advanced Hospital Management UI Collection

**User:** Sohni

## What changed
This version is not a repeated generic CRUD page. Every module has a domain-specific interface and data model.

### Modules
Dashboard • Patients • Doctors • Appointments • Emergency Center • Wards & Beds • Pharmacy • Laboratory • Billing • Medical Records • Prescriptions • Staff Management • Ambulance • Blood Bank • Insurance • Reports & Analytics • Notifications • Settings

### 4 template styles
Each module has:
1. Command Grid
2. Clinical Table
3. Timeline Flow
4. Insight Cards

## Working interactions
- Navigation
- Search/filter
- Add-record modal
- Delete
- CSV export
- Theme persistence
- Toast feedback
- Interactive bed map
- Notification panel
- Responsive mobile layout

## Run
Open `index.html` in a modern browser. No external dependencies are required.
