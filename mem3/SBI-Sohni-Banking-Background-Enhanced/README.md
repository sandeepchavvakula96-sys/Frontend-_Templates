# SBI SmartBank - Sohni
Fictional SBI-inspired educational banking dashboard.

## Working demo features
- All navigation links
- Dark/light mode
- Mobile menu
- Notifications
- Send Money modal
- Add Money
- Recharge
- Bill/UPI/Beneficiary demo actions
- Card block/unblock
- Budget edit
- Profile edit
- Transaction search
- CSV export
- Responsive UI

Open `index.html` to run.

This is a fictional educational demo. It is not an official SBI website and does not connect to real accounts, UPI, cards, or payments.
